# 👑 The Royal Wedding of Ananya & Vikramaditya
### *A Luxury Editorial Indian Wedding Invitation Experience*

An haute-couture digital wedding invitation inspired by royal Rajasthani palace aesthetics, Sabyasachi heritage stationery, and high-fashion editorial typography.

---

## 🎨 Creative Direction & Design System

### 1. Palette
- **Warm Ivory (`#FAF7F0`)**: Handcrafted deckle-edge cotton rag paper texture
- **Soft Champagne (`#E9DCC5`)**: Regal Silk and architectural marble undertones
- **Antique Gold (`#B69A62`)**: Zari embroidery, foil stamping, and scalloped filigree
- **Deep Espresso (`#30251F`)**: Calligraphic ink and editorial contrast
- **Muted Rose (`#C99B94`)**: Fresh Gulab petals and romantic warmth

### 2. Typography Hierarchy
- **Primary Serif Headings**: *Cormorant Garamond* (Light, Italic, Display weights with wide kerning)
- **Modern Clean Body**: *DM Sans* (Crisp editorial readability)
- **Calligraphic Accents**: *Great Vibes* (Romantic script touches)

---

## ✨ Features & Interactive Highlights

1. **3D Animated Wax Seal Envelope**:
   - Interactive burgundy wax seal stamped with the royal monogram (*A & V*)
   - Physical golden confetti particle explosion upon unsealing
   - 3D perspective flap flip & invitation card emergence
   - Replay button in the footer to re-live the wax seal ceremony anytime

2. **Ambient Royal Raag Audio Experience**:
   - Built-in soothing Shehnai, Tanpura drone, and acoustic Santoor melody synthesized via Web Audio API (zero external audio link dependencies)
   - Unobtrusive floating music player with play/pause and live soundwave animation

3. **Floating Marigold & Gold Petals**:
   - 60fps canvas particle system simulating delicate jasmine, rose petals, and gold leaf dust drifting across the screen
   - One-click toggle button to pause/resume

4. **Sacred Vedic Invocation & Royal Lineage**:
   - Line-art golden Ganesha motif with Sanskrit verse: *॥ श्री गणेशाय नमः ॥*
   - Formal invitation from the Roy & Sharma families honoring parents & grandparents

5. **Editorial Love Story (Our Chronicle)**:
   - High-fashion magazine timeline layout from Lake Pichola to the starlit proposal in the Aravalli Hills

6. **The Multi-Day Wedding Festivities**:
   - Distinct cards for *Welcome Mehndi*, *Royal Sangeet*, *Haldi & Phoolon Ki Holi*, and *Sacred Pheras & Reception*
   - **One-click "Save iCal (.ics)"** file generator
   - **One-click Google Calendar** synchronization
   - Attire moodboard with color swatches & tooltips

7. **Live Royal Countdown**:
   - Real-time countdown to Saturday, November 14, 2026, 4:30 PM IST

8. **Destination Jagmandir Island Palace & Google Maps**:
   - Interactive embedded map, direct Google Maps link, private boat transfer details from Bansi Ghat, airport concierge, and weather guide

9. **Interactive RSVP with Royal Guest Pass**:
   - Multi-guest selection, event attendance checklist, dietary gourmet preferences, and Sangeet song request
   - Generates a **Personalized Royal Digital Guest Pass** with unique serial number (e.g., `UDR-2026-AV4829`)
   - Persists state in `localStorage`

10. **Live Blessing Wall**:
    - Guests can inscribe personalized blessings and view warm wishes from friends and family

11. **Social Sharing**:
    - Instant WhatsApp invitation share and one-click link copy

## 🚀 Running the Project

```bash
cd wedding-invitation
npm run dev
```

Open `http://localhost:5173` in your browser.

To generate a static build for hosting on Vercel, Netlify, or GitHub Pages:
```bash
npm run build
```
The optimized bundle is output to `dist/`.
